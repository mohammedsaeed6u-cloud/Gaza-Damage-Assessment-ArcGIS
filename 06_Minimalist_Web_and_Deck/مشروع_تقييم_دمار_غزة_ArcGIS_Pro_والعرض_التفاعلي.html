خطوات التنفيذ العملي داخل ArcGIS Pro (Practical Tool Sequence — No Equations)

مسار الأدوات والمعاملات التطبيقية التي تم تنفيذها داخل برنامج ArcGIS Pro لإنتاج هذه النتائج المعتمدة:

الخطوة 01 Coordinate Standardization

توحيد نظام الإسقاط وضبط المسقط المتري

المسار: Ribbon > Analysis > Tools > Project
المدخلات: gaza_osm_buildings.geojson & pse_admin2.shp
نظام الإسقاط المخرج: WGS 1984 UTM Zone 36N (WKID: 32636)
الهدف: قياس المساحات والمسافات بالأمتار الصفرية التشويه.
الخطوة 02 Topology Sanitization

إصلاح العيوب الهندسية واستبعاد الشظايا

المسار: Data Management Tools > Features > Repair Geometry
المعالجة: حذف التقاطعات الذاتية وعكس الحلقات غير المغلقة.
تصفية الشظايا: Select by Attributes: Shape_Area >= 10.0
النتيجة: استبعاد 3,708 شظية واستقرار 326,448 مبنى نظيف في Gaza_Buildings_Clean.
الخطوة 03 Spatial Association

الربط المكاني وتصنيف درجات التدمير

المسار: Analysis Tools > Overlay > Spatial Join
معامل البحث: Match Option: CLOSEST | Search Radius: 5.0 Meters
حقل التصنيف: إضافة حقل حالة_المبنى (مدمر كلياً، دمار شديد، دمار متوسط، سليم).
الطبقة الناتجة: Buildings_Classified_AR داخل قاعدة Gaza_GIS_Master.gdb.
الخطوة 04 Density & Hotspots

توليد الكثافة الحرارية للدمار (Kernel Density)

المسار: Spatial Analyst Tools > Density > Kernel Density
حجم الخلية ونصف القطر: Output Cell Size: 10m | Search Radius: 500m
حقل الترجيح: Population Field: Damage_Weight (1.0 to 0.4)
الراستر الناتج: Kernel_Density_Damage_10m.tif.
الخطوة 05 Zonal Tabulation

تجميع الإحصائيات المكانية للمحافظات

المسار: Analysis Tools > Statistics > Summarize Within
المضلعات الحاكمة: Gaza_Governorates_AR
المباني المتضررة: حساب الإجمالي والنسب وتصدير Gaza_Governorate_Final_Stats.csv.
الناتج الإجمالي: 149,055 مبنى متضرر و 125.96 مليون طن ركام.
الخطوة 06 Cartographic Publishing

إخراج وتصدير اللوحات الكارتوغرافية A3

المسار: Share > Export Layout > PDF / PNG (300 DPI)
الشروط المحققة: شبكة مترية خارجية (5,000م)، سهم شمال، مقياس رسم، ومفتاح عربي.
اللوحات المعتمدة: 3 لوحات ماستر جاهزة للطباعة الفورية.
