دليل العمل التطبيقي في ArcGIS Pro الفصل 1: إنشاء قاعدة البيانات الجغرافية
الفصل الأول

إنشاء قاعدة البيانات الجغرافية وتوحيد نظام الإسقاط

تعتمد سلامة التحليلات المكانية وقياس المساحات بدقة على توحيد نظام الإسناد الجغرافي لكافة الطبقات. تم اعتماد مسقط ميركاتور المستعرض العالمي UTM Zone 36N (WGS 84) المعتمد رسمياً في فلسطين وقطاع غزة، حيث يقاس بالمتر ويحقق دقة حسابية عالية للأطوال والمساحات.

الخطوة 1.1
إنشاء قاعدة البيانات الجغرافية المكانية (File Geodatabase)

من نافذة الكتالوج (Catalog Pane)، انقر بيمين الفأرة على مجلد المشروع واختر:

Catalog Pane -> Right-Click Folder -> New -> File Geodatabase

قم بتسمية قاعدة البيانات باسم: Gaza_FullStrip_Master.gdb واجعلها قاعدة البيانات الافتراضية للمشروع (Set as Default GDB).

الخطوة 1.2
توحيد نظام الإسقاط للطبقات عبر أداة Project

إذا كانت الطبقات الخام محملة بنظام الإحداثيات الجغرافية WGS 1984 (EPSG: 4326)، يجب إعادة إسقاطها إلى UTM Zone 36N:

Geoprocessing -> Toolboxes -> Data Management Tools -> Projections and Transformations -> Project
المعامل (Parameter)القيمة المطلوبة
Input DatasetGaza_Governorates_Raw.shp / UNOSAT_Points_Raw.shp
Output DatasetGaza_FullStrip_Master.gdb\Gaza_Governorates_ADM1
Output Coordinate SystemWGS 1984 UTM Zone 36N (WKID: 32636)
قاعدة هندسية: يجب أن تشترك جميع الطبقات في مسقط UTM 36N لتفادي أخطاء التحويل الفوري (On-the-fly Projection) أثناء حساب الكثافات والمساحات.
دليل العمل التطبيقي في ArcGIS Pro الفصل 2: معالجة وقص المرئيات الفضائية
الفصل الثاني

استيراد ومعايرة وقص المرئيات الفضائية (Sentinel-2)

تغطي الدراسة 5 مراحل زمنية متتالية باستخدام مرئيات القمر الصناعي الأوروبي Sentinel-2 L2A بدقة مكانية 10 أمتار، خالية تماماً من الغيوم والدخان بنسبة تغطية 0.0% فوق كامل قطاع غزة.

الخطوة 2.1
دمج النطاقات الطيفية الطبيعية (Composite Bands)

لإنشاء مرئية ذات ألوان طبيعية حقيقية (True Color RGB):

Geoprocessing -> Data Management Tools -> Raster -> Raster Processing -> Composite Bands
المعاملالقيمة
Input RastersB04 (Red 665nm), B03 (Green 560nm), B02 (Blue 490nm)
Output RasterSentinel2_TrueColor_Composite.tif
الخطوة 2.2
قص المرئية على حدود قطاع غزة وإخفاء المناطق الخارجية (Clip Raster)

لقص المرئيات على مضلع قطاع غزة المعتمد وإخفاء البلدات الإسرائيلية المجاورة:

Geoprocessing -> Data Management Tools -> Raster -> Raster Processing -> Clip Raster
المعاملالقيمة
Input RasterSentinel2_TrueColor_Composite.tif
Output ExtentGaza_Governorates_ADM1 (Boundary Polygon)
Use Input Features for Clipping GeometryChecked (مفعل لقص الشكل الدقيق)
NoData Value0 (يظهر شفافاً أو بلون البحر المحدد)
الخطوة 2.3
معايرة التباين الإشعاعي الموحد (Radiometric Stretch)

من لوحة Symbology للمرئية، اختر نمط التمدد Percent Clip مع ضبط الحد الأدنى على 2.0% والحد الأعلى على 98.0% مع قيمة Gamma موحدة = 1.15 لضمان تطابق الإضاءة بين المراحل الزمنية الخمس.

دليل العمل التطبيقي في ArcGIS Pro الفصل 3: ترميز وتصنيف نقاط UNOSAT
الفصل الثالث

إدخال وترميز نقاط التدمير المعتمدة (UNOSAT)

تضم قاعدة بيانات مركز الأمم المتحدة للأقمار الصناعية (UNOSAT) 163,940 منشأة متضررة مؤكدة تم رصدها عبر الأقمار الصناعية عالية الدقة (30-50 سم). يتم تمثيل كل منشأة بنقطة جغرافية مصنفة إلى 3 مستويات رئيسية للأضرار.

الخطوة 3.1
تطبيق التصنيف القيمي الفريد (Unique Values Symbology)

من لوحة Symbology الخاصة بطبقة UNOSAT_Damage_Points_FullStrip:

Layer Properties -> Symbology -> Primary Symbology: Unique Values
الفئة (Class)الرمز واللونالحجمالإجمالي بالقطاع
مدمر كلياً (Destroyed)أحمر قاني (#B91C1C)3.5 pt67,730 منشأة

الخطوة 3.2
إلغاء التسميات النصية فوق الخريطة (Zero On-Map Text)

لضمان نقاء المرئيات الفضائية وعدم حجب نقاط الدمار:

Map Tab -> Labeling Group -> Uncheck 'Label Features' (layer.showLabels = False)

يتم إلغاء التسميات النصية على كافة الطبقات داخل إطار الخريطة، والاعتماد حصرياً على مفتاح الخريطة الخارجي في لوحة الإخراج.

تحذير كارتوغرافي: وجود 163 ألف اسم أو تسمية نصية فوق الخريطة يؤدي إلى تشوه بصري كامل (Label Overlap). الحفاظ على الخريطة خالية من النصوص قاعدة أكاديمية صارمة.

دليل العمل التطبيقي في ArcGIS Pro الفصل 6: تصميم لوحة الإخراج الطباعي A3
الفصل السادس

تصميم لوحة الإخراج A3 وتنظيف مفتاح الخريطة

الإخراج الكارتوغرافي النهائي هو واجهة البحث العلمي. يوضح هذا الفصل كيفية بناء مخطط A3 أفقي بمواصفات النشر الأكاديمي، وتنظيف مفتاح الخريطة تماماً من أسماء قنوات المرئيات (Band_1/Band_2).

الخطوة 6.1
إنشاء صفحة الإخراج A3 Landscape
Insert Tab -> New Layout -> ISO A3 Landscape (420 mm x 297 mm)

قم بإنشاء 5 إطارات خرائط متزامنة رأسية (Map Frames) بنفس مقياس الرسم ونفس الامتداد الجغرافي لكامل قطاع غزة.

الخطوة 6.2
تنظيف مفتاح الخريطة (Legend Properties) وإزالة قنوات الصور

عند إدراج مفتاح الخريطة (Legend)، يقوم ArcGIS Pro تلقائياً بإضافة قنوات المرئيات الفضائية (Red: Band_1). لإزالتها:

Format Legend Pane -> Legend Items -> Select Raster Layers -> Click Delete / Remove Item

يجب الإبقاء فقط على طبقات الفيكتور: حدود المحافظات الخمس، نقاط تصنيف UNOSAT، ودرجات الكثافة الحرارية، مع كتابة المسميات باللغة العربية الواضحة دون أي شرطات سفلية.

الخطوة 6.3
إدراج مقياس الرسم وسهم الشمال وشبكة الإحداثيات
  • مقياس الرسم: اختر مقياساً خطياً مترياً بالكيلومتر فقط (Scale Line Metric)، واضبط وحدات القياس على Kilometers (0 — 5 — 10 كم).
  • سهم الشمال: اختر سهم شمال كلاسيكي أنيق مع حرف (ش) أو (N) في ركن اللوحة الخارجي.
  • التصدير النهائي: من تبويب Share اختر Export Layout واضبط الصيغة على PDF / PNG بدقة 300 DPI ومساحة ألوان RGB مع تفعيل دمج الخطوط (Embed Fonts).
